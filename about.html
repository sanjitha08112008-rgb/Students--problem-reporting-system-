🎓 Student Problem Reporting System

About the Project

📖 About This Project

The Student Problem Reporting System is a simple web-based application designed to help students report problems and check their status.

The administrator can view submitted problems, update their status, set priority and manage reported problems.

🎯 Project Objective

The main objective of this project is to provide an easy and organized way for students to report college-related problems and track their progress.

✨ Main Features

📝 Student Problem Submission
🆔 Unique Problem ID Generation
🔎 Problem Status Tracking
📋 Problem History
🛠️ Admin Problem Management
⭐ Priority Management
📊 Status Progress Tracking

🔄 System Workflow

Student Login → Submit Problem → Problem ID Generated → Admin Reviews Problem → Admin Updates Status → Student Tracks Status → Problem Resolved

💻 Technologies Used

🌐 HTML
🎨 CSS
⚡ JavaScript
💾 Browser Local Storage
