❓ Help Center

Student Problem Reporting System

📌 How to Report a Problem?

1️⃣ Login

Login to the system using your student account.

2️⃣ Select Category

Select the category related to your problem.

3️⃣ Describe Problem

Enter a clear description of your problem.

4️⃣ Submit

Click the Submit button to report your problem.

5️⃣ Get Problem ID

A unique Problem ID will be generated.

6️⃣ Track Status

Use the Track Problem option to check the status.

❔ Frequently Asked Questions

Q: How do I report a complaint?

Login → Report Problem → Select Category → Describe → Submit.

Q: How can I check my complaint?

Open Track Problem and check your Problem ID and status.

Q: What are the complaint statuses?

Submitted, In Progress, and Resolved.

Q: What if my problem is not solved?

You can contact the concerned college administration.
