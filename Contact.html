Student Problem Reporting System

❓ How to Report a Problem

1️⃣ Login as a Student.
2️⃣ Open the Student Portal.
3️⃣ Enter the problem title and description.
4️⃣ Press Submit Problem.
5️⃣ Save the generated Problem ID.

🔎 How to Track a Problem

1️⃣ Open Track Problem.
2️⃣ Enter your Problem ID.
3️⃣ Press Track Problem.
4️⃣ Check the latest status.

🛠️ Admin Help

Admin can view all submitted problems.
Admin can search and filter problems.
Admin can update problem status.
Admin can set problem priority.

📧 Contact

For project-related assistance, contact the college administration or project guide.
