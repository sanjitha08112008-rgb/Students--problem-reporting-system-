🎓 Student Problem Reporting System

Report • Track • Resolve

Welcome to Student Problem Portal

A simple system for students to report their problems and track the status until resolution.

📌 About This Project

The Student Problem Reporting and Tracking System helps students submit problems and allows administrators to manage and update their status.

Each submitted problem receives a unique Problem ID which can be used to track its progress.

⭐ Main Features

📝

Report Problem

Students can submit their problems easily.

🆔

Problem ID

A unique ID is generated for every problem.

🔎

Track Status

Students can check the current status.

📋

Problem History

View previously submitted problems.

🛠️

Admin Management

Admin can update problem status.

⭐

Priority

Problems can be assigned Low, Medium or High priority.

🔄 Working Flow

Student Login → Submit Problem → Problem ID Generated → Admin Reviews → Status Updated → Student Tracks Problem
