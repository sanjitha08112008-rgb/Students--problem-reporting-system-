🎓 Student Problem Reporting System

Project Information

📌 Project Title

Student Problem Reporting and Tracking System

🎯 Objective

To provide a simple digital platform where students can report college-related problems and track their status until resolution.

⚙️ Modules

  1. Student Login
  2. Admin Login
  3. Problem Submission
  4. Problem ID Generation
  5. Problem Tracking
  6. Problem History
  7. Status Management
  8. Priority Management

💻 Technologies Used

🌐 HTML
🎨 CSS
⚡ JavaScript
💾 Local Storage

🔄 Working Flow

Student Login → Submit Problem → Generate Problem ID → Admin Reviews → Update Status → Student Tracks → Problem Resolved

🚀 Future Enhancements

  • Online database
  • Real student accounts
  • Email notifications
  • File/image attachments
  • Admin analytics dashboard
  • Mobile application
